# Current implementation

RoamingRuru is a Three.js mall robot demo with tool-using OpenAI conversation, ElevenLabs speech, Firecrawl official-source discovery, Convex visitor memory/mailing subscriptions and AgentMail shortlist delivery.

The 2:50 film includes a real recorded request that invokes `show_mailing_qr` and opens an empty signup form. Local live conversation, clothing vision, speech and official discovery have been exercised. Convex persistence/read/deletion and one bounded synthetic email send/reply exchange were verified.

90 unit tests and the Sites build pass. Desktop/mobile film, navigation and signup journeys are covered. Physical hardware and production recognition accuracy are outside this prototype.
